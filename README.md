# Selim Finance — القوائم المالية والزكاة

تطبيق ويب (PWA) لبناء القوائم المالية وحساب الزكاة من ميزان المراجعة.
React + Firebase (مصادقة + Firestore).

---

## ⚠ اقرأ ده الأول: طريقة التعديل اتغيّرت

قبل كده كان الكود كله جوّه `index.html` وبابل بيترجمه في متصفح كل مستخدم.
دلوقتي فيه خطوة بناء.

| الملف | إيه هو |
|---|---|
| **`app.src.jsx`** | 👈 **الكود اللي بتعدّل فيه.** كل التطبيق هنا. |
| `app.js` | مُولَّد تلقائيًا. **متعدلوش** — أي تعديل هيضيع مع أول بناء. |
| `index.html` | قشرة بسيطة بتحمّل المكتبات و `app.js`. نادرًا هتحتاج تلمسها. |
| `sw.js` | Service Worker — بيخلّي التطبيق يفتح من غير إنترنت. |
| `firestore.rules` | قواعد أمان Firestore. **لازم تتنشر يدويًا** (تفاصيل تحت). |
| `build.mjs` | سكربت البناء. |

### خطوات التعديل والنشر

```bash
npm install        # مرة واحدة بس
# ... عدّل في app.src.jsx ...
npm run build      # بيولّد app.js ويحدّث رقم النسخة في index.html و sw.js
```

بعدين ارفع الملفات دي:

```
index.html   app.js   sw.js   manifest.json   icon-192.png   icon-512.png
```

**مهم:** لو رفعت `app.src.jsx` من غير ما تشغّل `npm run build`، التطبيق
المنشور هيفضل على الكود القديم — لأن المتصفح بيقرأ `app.js` مش المصدر.

### رقم النسخة

مصدره الوحيد `APP_VERSION` في `app.src.jsx`. غيّره هناك بس، و`npm run build`
هيوزّعه على `index.html` و`sw.js` لوحده. الرقم ده هو اللي بيخلّي المستخدمين
ياخدوا النسخة الجديدة بدل القديمة المخزّنة.

## نشر قواعد الأمان (خطوة لازمة)

ملف `firestore.rules` **مش بيتنشر لوحده**. من غير نشره، البيانات محمية
بإعدادات كونسول فايربيز الحالية بس — واللي التطبيق مش بيتحقق منها من جهته أصلاً.

```bash
npm install -g firebase-tools
firebase login
firebase deploy --only firestore:rules --project selim-financ
```

أو من الكونسول: Firestore Database ← Rules ← الصق محتوى الملف ← Publish.

**قبل النشر:** استخدم Rules Playground في الكونسول وجرّب:
- مالك بيقرا شركته ✅
- مستخدم غريب بيحاول يقرا شركة مش بتاعته ❌
- محرّر بيحاول يضيف نفسه في `editorEmails` ❌

## تفعيل البريد الإلكتروني

التطبيق بقى يبعت رسالة تفعيل تلقائيًا عند إنشاء أي حساب، وبيعرض شريط تنبيه
لأي مستخدم بريده مش مفعّل.

**الدخول لسه مسموح لغير المفعّلين عن قصد** — قفله دلوقتي معناه إن كل المستخدمين
الحاليين يتقفل عليهم فجأة.

**الخطوة الجاية (لما الكل يفعّل):** شيل التعليق عن السطر ده في `firestore.rules`
عشان القفل يبقى على السيرفر مش الواجهة بس:

```
&& request.auth.token.email_verified == true
```

## العمل من غير إنترنت

`sw.js` بيخزّن قشرة التطبيق والمكتبات المثبّتة، فالتطبيق بيفتح من غير نت
بعد أول زيارة. البيانات نفسها (Firestore) محتاجة نت طبعًا.

الاستراتيجية: **الشبكة أولاً** لملفات التطبيق — يعني وانت أونلاين بتاخد آخر
نسخة دايمًا. ده مقصود: في تطبيق محاسبي، مستخدم شغّال على كود قديم فيه خطأ
حسابي اتصلّح خلاص = أرقام غلط وهو مش واخد باله.

زر «تحديث التطبيق» في الواجهة بيمسح الكاش **ويلغي تسجيل الـ Service Worker**
قبل إعادة التحميل.
